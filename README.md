# Expense Tracker

A React + Vite expense tracker built to match the spec in the attached PDF. It includes:
- adding expenses with validation
- category filtering
- a running total and visible count
- delete actions
- unit/component tests and Cypress E2E coverage

## Commands
- `npm install`
- `npm run dev`
- `npm run build`
- `npm test`
- `npm run test:run`
- `npm run coverage`
- `npm run cy:open`
- `npm run cy:run`
